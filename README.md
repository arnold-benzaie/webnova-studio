## 🚀 Déploiement

### Vercel (recommandé — gratuit)

```bash
# Installer Vercel CLI
npm i -g vercel

# Déployer
vercel --prod
```

### Domaine `webnova.mu`

1. Acheter le domaine via [Mauritius Network Information Centre](https://nic.mu/) ou [LinkByNet Mauritius](https://www.lbn.mu/)
2. Dans Vercel → Project Settings → Domains → Add `webnova.mu`
3. Configurer les DNS chez votre registrar :
   - Type `A` → `76.76.21.21` (Vercel)
   - Type `CNAME` `www` → `cname.vercel-dns.com`
